# 更新记录

## 0.1.0-preview.6 - 2026-10-21

- 抽取不依赖 Unity 的共享核心，提供 Unity 和 .NET 注册根对象/执行线程 Adapter，两端使用同一套反射、计划和传输。
- 添加显式启用的可选 Roslyn 同步脚本、脚本参数、共享对象句柄、操作编号去重与失败回执；支持本机 HTTP 和中转 MCP。
- 提供 .NET Standard 2.0 项目引用与可选 Unity 模块构建工具；默认反射安装不引入 Roslyn DLL。
- 直接构造反射会话的 Unity 使用方须显式传 UnityReflectionHost；既有 ClientMcpRuntime 及外部反射/计划协议保持兼容。

## 0.1.0-preview.5 - 2026-10-17

- 添加可选 WSS 出站连接，与本机入口共用主线程反射执行器、操作说明和计划缓存。
- 添加 ASP.NET Core 中转及 MCP 在线实例查询，每次显式选择目标实例；开发者与客户端令牌分离。
- 添加有界请求路由、心跳、断线重连和等待清理；不自动重发写入，断线取消尚未执行的请求。
- MCP 工具定义由 Runtime 和中转共用，避免维护两份反射接口。

## 0.1.0-preview.4 - 2026-10-17

- 添加通用反射操作计划：准备、执行、回执查询、列表与显式释放，不依赖 Editor 或动态代码编译。
- 支持本次参数和前序结果引用，短步骤在同一主线程回调顺序执行；失败停止并保留部分结果，不自动回滚。
- 以当前会话和操作编号保护重复执行，原失败也可查询；设置明确容量且不自动淘汰去重记录。
- MCP 提示和使用说明明确优先复用计划、区分新执行与重试；Python 新增五个轻量计划封装。

## 0.1.0-preview.3 - 2026-10-17

- 添加 Unity 连接状态窗口，显示监听状态、连接入口、分类请求计数和最近 16 条请求结果，并共用 Editor 启用开关。
- 添加运行时连接状态快照，区分 MCP、反射 HTTP 与健康检查；保留操作标识与调用方说明，不自动记录参数或返回值。
- `/health` 与 `clientmcp_status` 在原结果中新增 `connection`，可由外部工具读取同一状态；监听不推断持久在线客户端。
- 反射操作新增必填 `description`，在 Unity Console 显示执行说明和成功或失败；旧原始 JSON / MCP 调用需要补充该字段。Python 方法可显式覆盖说明，省略时自动提供通用中文说明。

## 0.1.0-preview.2 - 2026-10-17

- 实现类型与对象查找、成员元数据、字段和属性读写、对象构造、实例与静态方法调用。
- 实现对象句柄、引用参数、明确的重载选择、结构值副本与句柄释放。
- 添加显式启用的本机 HTTP 与 MCP JSON 接入、随机令牌、主线程队列及请求执行前超时取消。
- 添加标准库 Python 外部脚本客户端，以及独立于包的通用验证夹具。
- 最低 Unity 版本声明调整为 2022.3，保留 Unity 6000.5 对象标识 API 的必要适配。

## 0.1.0-preview.1 - 2026-09-30

- 建立 UPM 包清单和独立运行时程序集骨架。
- 建立 Unity 6000.5.9f1 开发验证工程及 Git URL 发布说明。
- 本版本不包含 MCP 服务、反射查询或远程诊断实现。
