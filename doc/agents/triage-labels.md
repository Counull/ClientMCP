# Triage labels

| 技能角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 需求及验收标准已明确，可交给 Agent 执行 |
| ready-for-human | ready-for-human | 需要人工处理 |
| wontfix | wontfix | 当前决定不实施 |

技能引用分类角色时使用此映射。标签不扩大修改、外部通信或推送权限。

本次仅写入标签约定，不修改 GitHub 现有标签；执行已授权的分流任务时，先检查远端标签，按需补齐，保留现有同名标签。
